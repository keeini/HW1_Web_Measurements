## Tool Used

- ChatGPT
- Model: GPT-5.6 Sol

## How AI Was Used

I used ChatGPT as an assistant while completing the assignment. I used it mainly to help configure the Web Scraper and organize my written responses.

All experimental commands were run by me on my own machine. The saved headers, HTML files, hashes, screenshots, and exported scraper data were produced from my own experiment and were not generated by ChatGPT.

## Relevant Prompts

Some of the relevant prompts or questions I gave ChatGPT included:
- How can I use Web Scraper to extract reviewer name, rating, date, review text, and business name from the Yelp page?
- How can I extract Yelp's star rating when the rating is stored in an `aria-label` attribute?

## Suggestions Accepted

I accepted several suggestions from ChatGPT, including:
- Using an Element Attribute selector in Web Scraper to extract the Yelp rating from the `aria-label` attribute.
- Structuring the Web Scraper sitemap with a repeated review element and child selectors for reviewer, rating, date, and review text.

## Suggestions Rejected or Modified

I modified some suggested responses pertaining to Web Scraper because the initial answers did not always match what I was seeing in the extension. For example, some suggestions assumed that I could directly create certain selector types from the interface I was using, but the options available depended on whether I was using the basic extension view or the advanced sitemap builder in Dev Tools.

## Error or Weak Assumption Identified

Some of the errors or weak assumptions came from ChatGPT not distinguishing the records coming from Chat itself or from the Yelp page I actually needed to scrape. It was difficult in general working with AI on this section since I was fairly new to use Web Scraper as well.
